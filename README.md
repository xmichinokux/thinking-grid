# 思考の座標

AI の案が無難で物足りないときに、頼みの前に貼る文を作るページです。
抽象度と飛躍度の位置を選ぶと、文ができます。AI は呼ばないので、鍵も費用も要りません。

**ページ:** https://xmichinokux.github.io/thinking-grid/

## 文の形

下の文の `{抽象度}` と `{飛躍度}` を、ほしい案に合わせて入れ替えます。

```text
【考え方】
- {抽象度}
- 個別の問いに答えつつ、一般原理から引く
- 表層の事実でなく、根底のメカニズムまで見る
- {飛躍度}

浅い・個別すぎる・表層の切り口は削る。

「お題」について、アイデアを 5 つ出してください。
```

| つまみ | 低 | 高 |
|---|---|---|
| 抽象度 | 抽象的な言い方を避け、来週から動ける具体的な行動で書く | 根底の原理・メカニズムを優先する |
| 飛躍度 | 別分野との軽い掛け合わせにとどめ、SF 的な飛躍はしない | 遠い別分野の仕組みを大胆に持ち込み、常識から外れた案も出す |

## 測った結果

2026 年 11 月に測りました。お題は身近な 5 つです。案は Claude Haiku 4.5 と Gemini 2.5 Flash が作り、Claude Opus 4.7（1 回）と Gemini 2.5 Flash（順を変えて 2 回）が、足した文を見ずに採点しました。

### 足すと案は変わるか

「案の中身が安易でないか」の 5 点満点です。お題ごとに 3 回ずつ作りました。表の点は Opus の採点です。文はつまみを入れる前の形（抽象 高・飛躍 低）で、1 行は「浅い・個別すぎる・表層の切り口は削る。」だけを足したものです。

| 足したもの | Haiku の字数 | Haiku の案 | Gemini の字数 | Gemini の案 |
|---|---|---|---|---|
| 何も足さない | 492 | 1.87 | 1,850 | 2.33 |
| 「それぞれ詳しく書いてください。」 | 1,082 | 2.13 | 4,862 | 2.60 |
| 1 行 | 526 | 3.80 | 1,951 | 3.87 |
| 文全体 | 885 | 4.93 | 2,673 | 4.27 |

Gemini の採点でも順位は同じでした。

### つまみを動かすと案は変わるか

お題ごとに 2 回ずつ作りました。作る AI 2 種と採点者 2 種の、4 通りの幅です。

| 動かしたもの | 「具体的か」の変化 | 「常識の外か」の変化 |
|---|---|---|
| 抽象度を下げる | +1.57〜+2.25 | −0.55〜+0.30 |
| 飛躍度を上げる | −0.05〜+0.10 | +1.60〜+2.08 |

「次の話し合いに持っていきたいか」は、4 通りとも「抽象 低・飛躍 高」が最も高い点でした。この点は 4 つの位置を並べて比べたものです。

### 数字だけを動かすと案は変わるか

抽象度と飛躍度の数字を 1 と 5 で動かしました。お題は 5 つ、各 2 回です。「数字だけ」は軸の名前と数字だけの文、「言葉は固定」は言葉を同じままにして数字だけを変えた文です。

| 動かしたもの | 作った AI | 「具体的か」の変化 | 「常識の外か」の変化 |
|---|---|---|---|
| 数字だけ | Haiku | +0.55〜+0.75 | +0.75〜+0.88 |
| 数字だけ | Gemini | +3.45 | +3.02 |
| 言葉は固定 | Haiku | 0.00〜+0.20 | +0.30〜+0.40 |
| 言葉は固定 | Gemini | +0.03 | +0.75 |

「具体的か」は抽象度を下げたとき、「常識の外か」は飛躍度を上げたときの変化です。数字だけでも案は動きますが、言葉が一緒にあると、数字はほとんど効きませんでした。Gemini が作った案は Gemini だけが採点したので、大きめに出ている可能性があります。

## 弱い点

- 採点はどちらも AI です。人が読み比べたのは 1 人・5 題だけで、4 つの位置は人が読んでいません。
- 採点者が、賢そうな書き方を高く評価している可能性があります。
- 案には、裏付けのない断定が混ざることがあります。根拠は自分で確かめてください。
- つまみの測定では、採点の問いと足した文の言葉が近く、言われた通りに書いたかを見ている面があります。
- 「根底のメカニズム」のような硬い見出しが、どの位置でも出ることがあります。
- 動かしたのは 2 つの軸の高低だけです。5 段階の動きや、ほかの軸は確かめていません。
- 数字の測定は 1 と 5 の極端な差だけで、各 10 組です。
- ChatGPT では試していません。英語の文も試していません。
- 点が 5 に近く、差が出にくい所があります。Gemini の採点には、最初に置いた束を高く見る偏りがありました。

向いているのは、答えが一つに決まらない案出しです。別の測定では、仕様書を書く仕事では効果がなく、穴の洗い出しでは差が出ませんでした。その測定は Kokoro OS の頼み方を含むので、ここには置いていません。

## 測り直す

`bench/data/` に、作った案と採点の生データがあります。鍵がなくても、集計だけはやり直せます。

```bash
node bench/plain-run.mjs report
node bench/dial-run.mjs report
SET=N node bench/num-dial-run.mjs report
SET=W node bench/num-dial-run.mjs report
```

案の生成と採点もやり直す場合は、鍵を環境変数に入れます。Anthropic と Gemini の料金がかかります。今回はどちらの測定も、それぞれ 4 ドル前後でした。

```bash
export ANTHROPIC_API_KEY=...
export GEMINI_API_KEY=...
node bench/plain-run.mjs gen
node bench/plain-run.mjs judge
```

`dial-run.mjs` と `num-dial-run.mjs` も同じ手順です。`num-dial-run.mjs` は `SET=N`（数字だけ）か `SET=W`（言葉は固定）を付けて動かします。やり直すと `bench/data/` のファイルは上書きされます。Node.js 22 で確かめました。

## 生まれた場所

[Kokoro OS](https://usekokoro.com) の開発で、AI の考え方を 4 つの軸の数字で指定する「思考の座標」を試していました。測り直すと、数字だけでも案は動きますが、数字に添えた言葉があると、ほぼ言葉で決まりました。このページでは、数字を人が位置を選ぶためだけに使い、AI には言葉だけを渡します。
